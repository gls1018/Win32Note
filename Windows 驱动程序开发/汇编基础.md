

### 栈

在x86/x86_64中, 栈的增长方向是由高地址像低地址增长的.

栈底在高地址, 栈顶在低地址.

- Push后, RSP减小
- Pop后, Rsp增加



### lea 

lea是 Load Effective Address的缩写, 

```
lea dest src
```

作用是计算源操作数所表示的内存寻址表达式中的有效地址, 并将该地址值送入目的寄存器. 它不访问该内存地址, 也不读取其中的数据.





### call 和 Ret

call指令用于函数跳转.

call指令在硬件层面, 做以下事情. 

- 把call指令下一条指令地址Push到栈里面
- 修改RIP 为目标函数地址.
