### 1. 大端序和小端序



下面是一个32位整数.

```cpp
uint32_t num == 0x1234578;
```

- 0x12 : 最高有效字节 MSB
- 0x78 : 最低有效字节 LSB

如果从内存地址 1000 开始存储这个4字节的整数.



小端序: 高位字节放在高地址, 低位字节放在低地址.

```cpp
0x1000 → 0x78
0x1001 → 0x56
0x1002 → 0x34
0x1003 → 0x12
```



大端序: 低位字节放在高地址, 高位字节放在低地址.   **大端序和人类书写一致**

```cpp
0x1000 → 0x12
0x1001 → 0x34
0x1002 → 0x56
0x1003 → 0x78
```





下面代码可以验证是大端序,还是小端序

```cpp
int main()
{
    uint32_t x = 0x12345678;

    uint8_t* p = reinterpret_cast<uint8_t*>(&x);

    for (int i = 0; i < sizeof(x); ++i)
    {
        printf("%02X ", p[i]);
    }
}
```





### 2. 为什么会出现小端序



假设有一个整数

```
uint32_t num = 0x12345678;
```

它在内存中是这样的

```
78 56 34 12
```

现在 `uint8_t value = num;` 直接截断, 得到:

``` 
78
```

0x78刚好处于低位地

如果 `uint16_t value = num;` 截断得到:

```
78 56
```

小端序对于处理不同宽度的数据比较方便.
